# Health-State Transitions and the Cost of Aging: A Multi-State Actuarial Model of Lifetime Medicare Spending and Household Out-of-Pocket Tail Risk

A multi-state model of health-state transitions in later life, used to project lifetime Medicare spending and the out-of-pocket tail risk households carry as they age.

**Status.** Planned. Flagship paper of the programme. Code and results will be published here as the
analysis is completed.
